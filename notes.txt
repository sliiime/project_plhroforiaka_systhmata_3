One major issue with the JobScheduler is that it cannot be used concurrently by different threads, which makes it kind of useless. The main reason that this 
happens is that in order to have tasks execute in a specific order you need to submit them to the JobScheduler, use the wait method and then submit the tasks
that follow. This is obviously inefficient.

Different task types : 
    Task_1 wants to execute once Task_2 has executed.
    Task_1 wants to execute once Task_2 ... Task_n have executed.
    Task_1 wants to execute once Task_2 has executed which is a task that waits on N tasks to execute
